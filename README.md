# 🀄 万能麻将 - 中国麻将大全

一个使用原生 HTML、CSS、JavaScript 开发的网页版麻将游戏，提供 14 种麻将配置与基础对战流程，地方特殊玩法仍在开发中。

## ✨ 功能特性

### 🎮 游戏模式
- **人机对战** - 1人 vs 2~3个AI（支持多种难度）
- **局域网联机** - 2~4人 WebRTC 对战（需信令服务）
- **自定义模式** - 选择麻将种类并查看规则支持状态
- **牌局回放** - 查看历史对局记录

### 🀅 麻将配置
- 国标麻将（144张）
- 广东麻将（推倒胡）
- 四川麻将（血战到底、缺一门）
- 上海麻将（花牌计番）
- 北京麻将
- 台湾麻将（16张）
- 杭州麻将
- 长沙麻将
- 东北麻将
- 湖北麻将
- 福建麻将
- 江西麻将
- 湖南三人麻将
- 四川三人麻将

以上配置使用共用引擎与部分番型表，并非完整复刻各地规则。混儿、财神、赖子、扎鸟、抢杠等特殊流程尚未实现，规则面板标为“待实现”；国标番型与计分也属于当前实现的子集。

### 🎯 核心功能
- 基础吃、碰、杠、胡及操作优先级
- 自摸、杠上开花、海底捞月
- 七对、十三幺等特殊牌型
- 暗杠、明杠、加杠
- 花牌补牌
- 流局判定
- 番数计算

### 🎨 个性化设置
- 7种牌桌主题（经典绿、深海蓝、原木色、中国红、紫晶、墨色、落日）
- 对手手牌显示方式（隐藏/小牌堆/完整显示）
- 牌桌缩放、手牌大小调整
- 动画强度控制
- BGM/SFX音量控制
- 游戏速度调节

### 📊 统计与成就
- 等级与经验系统
- 胜率、连胜记录
- 总得分、最高单局
- 17项成就待解锁
- 历史对局记录

## 🚀 快速开始

### 本地运行
```bash
# 终端 1：启动静态页面
npm run client

# 终端 2：启动联机信令服务
npm run server
```

然后在浏览器中打开 `http://localhost:8080`

### GitHub Pages 部署

将仓库推送到 `main`，在仓库 **Settings → Pages** 中选择从 `main` 分支的根目录发布。本项目为静态页面，无需安装运行时依赖或构建前端。

站点地址为 `https://hanazar-games.github.io/Mahjong-Webgame/`。资源、安装入口和离线缓存均使用项目子目录；缓存按站点路径隔离。发布后检查 Pages 构建状态，并重新打开或刷新页面取得新版本。

Pages 仅托管页面，不能运行 Node.js 信令服务。单机、设置、回放和音频可直接使用；联机需要另行部署信令服务，为其配置 HTTPS，并让所有玩家填写同一服务地址。服务器的允许来源应使用页面的 origin，不含项目路径，例如：

```bash
ALLOWED_ORIGINS=https://hanazar-games.github.io NODE_ENV=production npm run server
```

上述命令启动 HTTP 后端，HTTPS 由部署平台或反向代理提供。HTTPS 页面不接受普通 HTTP 局域网地址；本机回环地址可用于开发调试。跨网络连接仍取决于 WebRTC 的网络可达性，当前项目没有提供公共信令或 TURN 服务。

### 一键启动（仅适合 macOS / Linux shell）
```bash
npm start
```

### 直接打开
由于游戏使用纯前端技术（HTML/CSS/JavaScript），也可以直接在浏览器中打开 `index.html` 文件。

**注意**：
- 局域网联机需要同时启动 `8080` 静态页面和 `8081` 信令服务。
- 直接打开 `index.html` 只适合单机查看，不适合联机。
- 默认允许同一主机 `8080` 端口页面访问联机服务；使用其他前端地址时设置 `ALLOWED_ORIGINS`，多个地址用逗号分隔。
- 单机菜单会暂停牌局，联机菜单不会暂停其他玩家；结算后由房主再开一局，房主退出会关闭房间。

## 🎮 操作说明

### 游戏内操作
- **点击手牌** - 选中/取消选中
- **再次点击已选中的牌** - 打出
- **1** - 吃
- **2** - 碰
- **3** - 杠
- **4 / 空格** - 胡
- **S** - 跳过
- **ESC** - 打开游戏菜单

### 快捷键
- 支持键盘快捷键进行吃碰杠胡操作
- 移动端支持触摸手势
